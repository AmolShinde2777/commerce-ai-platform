# Commerce AI Platform

An AI-first commerce platform that demonstrates how AI can manage commerce operations using natural language and tool calling.

## Tech Stack

- .NET 10
- ASP.NET Core Minimal APIs
- Clean Architecture
- PostgreSQL + EF Core
- React + TypeScript
- Vercel
- Railway
- Neon PostgreSQL
